# SourceSay

Free WooCommerce plugin by [Swift Web Dev](https://swiftwebdev.com/). After checkout, SourceSay asks customers one short question: how did you hear about us? Their answers show which channels really bring orders, including word of mouth, podcasts and other channels that analytics tools miss.

- WordPress.org: https://wordpress.org/plugins/sourcesay/
- Requires WordPress 6.5+, PHP 7.4+, WooCommerce
- License: GPLv2 or later

See [readme.txt](readme.txt) for the full description.

## Releasing

Bump `Version` in `sourcesay.php` and `Stable tag` in `readme.txt`, add a changelog entry, then push a tag with the same version number (for example `1.0.1`). The workflow publishes it to WordPress.org. Listing images live in `.wordpress-org/`.
